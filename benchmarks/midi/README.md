## Use Cases

These files are suitable for:
- MIDI parsing and analysis benchmarks
- Audio synthesis quality testing
- Music information retrieval (MIR) experiments
- DAW import/export validation
- Piano roll visualization testing

## Validation

All files have been verified as valid Standard MIDI Format (SMF) files:
- Format 0: Single track (some files)
- Format 1: Multi-track (most files)
- Resolution: 384-480 ticks per quarter note
